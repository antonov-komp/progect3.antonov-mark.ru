## Назначение
Хранить "нулевую" версию запросов перед оптимизацией.

## Формат
`DOCS/SQL/original-queries/TASK-XXX_method.sql`

## Шапка файла (обязательно)
```

-- Описание: краткое назначение запроса
```

- Запрос сохраняется "как есть", без правок.
- Секреты маскируются.
