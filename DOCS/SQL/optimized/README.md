# Оптимизированные SQL-запросы

Дата: 2026-01-14 21:42 (UTC+3, Брест)

## Назначение
Хранить оптимизированные версии запросов с обоснованием правок.

## Формат
`DOCS/SQL/optimized/TASK-XXX_method_v2.sql`

## Шапка файла (обязательно)
```
-- Оптимизировано: 2026-01-14 21:42 (UTC+3, Брест)
-- Причина: ...
-- Ссылка на задачу: TASK-XXX
```

## Правила
- Логику запроса не менять без согласования.
- Указывать только нужные столбцы (без SELECT *).
- При необходимости добавлять комментарии к сложным частям.
