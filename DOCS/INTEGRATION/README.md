## Быстрая справка

### Как работает приложение в Bitrix24

1. **Bitrix24 загружает приложение в iframe** с параметрами авторизации
2. **Backend получает контекст** через `RequestContextService` и сохраняет в сессии
3. **Frontend инициализирует BX24 SDK** для взаимодействия с порталом
4. **Приложение использует REST API** для работы с данными Bitrix24
5. **Все запросы авторизуются** через токены, переданные Bitrix24

### Ключевые компоненты

- `RequestContextService` — получение и сохранение контекста запроса
- `AccessContextService` — определение контекста доступа (embedded/direct)
- `Bitrix24Client` — клиент для работы с Bitrix24 REST API
- `bitrixSdk.js` — инициализация Bitrix24 SDK на фронтенде
