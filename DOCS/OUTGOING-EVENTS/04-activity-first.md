 # Activity First: стартовая логика под капотом
 
 Дата создания: 2026-01-23 18:38 (UTC+03:00, Брест)
 
 ## Назначение
 Activity First — это первая (базовая) проверка, запускаемая после обогащения
 событий задач/комментариев. Она определяет, нужно ли создавать «активность»
 по условному правилу.
 
 ## Где находится логика
 - Функция: `outgoingWebhookEvaluateActivityFirst()`  
   Файл: `outgoing-webhook/bootstrap.php`
 - Условия: `outgoing-webhook/activity/first/conditions.php`
 
 ## Входные данные
 В функцию передаётся массив `details`, собранный на этапе обработки задач:
 - `projectId` — проект задачи.
 - `crmLinks` — CRM‑связи задачи (например, ссылка/префикс сделки).
 - `message` — текст комментария/сообщения.
 - `fileIds` — список прикреплённых файлов.
 
 ## Условия срабатывания (фактический алгоритм)
 1. Если задан `projectId` в условиях — проект должен совпадать.
 2. В CRM‑связях должна быть ссылка на сделку (по префиксу или URL).
 3. Сообщение должно содержать одно из ключевых слов.
 4. Должны быть прикреплённые файлы.
 
 Если все проверки пройдены, функция возвращает `true` и в деталях
 устанавливается `activityFirst = true`.
 
 ## Псевдокод
 ```php
 $conditions = loadConditions();
 
 if (projectId не совпал) return false;
 if (нет ссылки на сделку в crmLinks) return false;
 if (нет ключевого слова в message) return false;
 if (fileIds пустой) return false;
 
 return true;
 ```
 
 ## Где задаются условия
 Файл: `outgoing-webhook/activity/first/conditions.php`
 
 Ключи:
 - `projectId` — ID проекта (строка).
 - `crmDealPrefix` — префикс связи сделки (например, `D_`).
 - `keywords` — массив ключевых слов для поиска в тексте.
 
 Значения зависят от проекта и могут отличаться между окружениями.
