## Назначение
Папка `DOCS/` содержит документацию для прототипирования и развития Bitrix24 REST
приложения с Vue 3 фронтендом: архитектура, задачи, планы, UI-стандарты и
технические ссылки.

## Быстрый старт
1. Ознакомьтесь с `ARCHITECTURE/tech-stack.md`.
2. Проверьте актуальные задачи в `TASKS/`.
3. Для UI и Vue-приложения — следуйте `GUIDES/ui-standards.md`.
4. Для контрактов UI-эндпоинтов — `API-REFERENCES/app-api.md`.

## Структура
- `ARCHITECTURE/` — архитектура, техстек и модель данных.
- `TASKS/` — задачи в формате `TASK-XXX-*.md` (с `archive/` и `backlog/`).
- `PLAN/` — планы работ, дорожные карты, риски.
- `GUIDES/` — гайды и стандарты (UI, процессы, код).
- `API-REFERENCES/` — справочники по API и SDK (Bitrix24 + эндпоинты приложения).
- `OUTGOING-EVENTS/` — документация по модулю исходящих событий Bitrix24.
- `DB-SCHEMA/` — документация структуры БД.
- `SQL/` — исходные и оптимизированные запросы и история.

## Правила оформления
- Даты: `YYYY-MM-DD HH:MM (UTC+3, Брест)`.
- Секреты не хранить в коде и документации (маскировать).
- Каждый документ — единая тема, без смешения разных разделов.
- Все изменения фиксировать кратким описанием внизу файла.
