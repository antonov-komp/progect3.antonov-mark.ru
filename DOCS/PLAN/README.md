# Планирование

Дата: 2026-01-14 21:42 (UTC+3, Брест)

## Содержание
- Дорожные карты релизов.
- План работ по задачам.
- Риски и зависимости.

## Рекомендуемый формат плана
1. Цель релиза.
2. Объем работ (ссылка на TASK-файлы).
3. Этапы и сроки.
4. Риски и меры снижения.
5. Ответственные.

## Пример структуры файла
```
# План релиза R1
Дата: 2026-01-14 21:42 (UTC+3, Брест)

## Цель
...

## Состав работ
- TASK-001-...
- TASK-002-...

## Этапы
1. ...
```
