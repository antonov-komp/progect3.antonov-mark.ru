# План рефакторинга Vue части (R1)

Дата: 2026-01-14 23:37 (UTC+3, Брест)

## Цель
Упростить и стабилизировать Vue‑фронтенд встроенного приложения Bitrix24: улучшить архитектуру, стандартизировать загрузку контекста, разделить UI и бизнес‑логику, повысить поддерживаемость.

## Контекст
- Фронтенд: Vue 3 (Vite), ассеты в `public/vue/`.
- Исходники: `frontend/` (сборка в `public/vue/`).
- Backend отдаёт контекст и JSON в `app/api/ui-state.php`.

## Аудит (срез)
- Нет явного слоя для работы с `ui-state`.
- UI и доступ/ошибки отображаются без единого стандарта.
- Сборка ассетов не документирована в контексте рефакторинга.

## Состав работ (TASK‑файлы)
- `TASK-008-refactor-vue-structure.md`
- `TASK-009-refactor-vue-state-data.md`
- `TASK-010-refactor-vue-ui-components.md`
- `TASK-011-refactor-vue-build-docs.md`

## Этапы
1. Аудит и постановка задач (закрыто этим планом).
2. Рефактор структуры и bootstrapping Vue.
3. Рефактор state/data слоя.
4. Рефактор UI‑компонентов и отображения статусов.
5. Рефактор сборки, ассетов и документации.

## Риски
- Несовместимость с контекстом Bitrix24 (embedded/direct).
- Регрессии при загрузке `ui-state` и обработке ошибок.

## Меры снижения
- Тестовые сценарии в каждом TASK‑файле.
- Разделение слоёв и строгие контракты данных.
