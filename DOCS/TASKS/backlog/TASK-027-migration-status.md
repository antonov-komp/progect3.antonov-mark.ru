## Использование

### Инициализация БД

```bash
php outgoing-webhook/tools/init-database.php
```

### Переключение на БД

В `config.local.php`:
```php
'DATABASE_TYPE' => 'sqlite',
```

### Переключение обратно на файлы

В `config.local.php`:
```php
'DATABASE_TYPE' => 'files', // или любое другое значение
```
