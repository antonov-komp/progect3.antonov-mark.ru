Исполнитель: Bitrix24 Vue.js

## Цель
Упорядочить UI‑компоненты, стандартизировать отображение статусов и уведомлений, обеспечить стилистику Bitrix24.

## Контекст
Интерфейс должен быть визуально совместим с Bitrix24 и корректно отображать состояния доступа и загрузки.

## Требования
### Функциональные
- Разделить UI на компоненты: Loader, ErrorState, AccessDenied, GreetingCard.
- Единый слой уведомлений через `BX.UI.Notification` при наличии SDK.
- Поддержка embedded/direct режимов в отображении.

### Нефункциональные
- Использовать стили Bitrix24 UI Kit (CSS‑переменные/классы).
- Компоненты должны быть переиспользуемыми.

## Модули/компоненты
- `frontend/src/components/`
- `frontend/src/styles/`
- `frontend/src/views/`

## Зависимости (иерархия)
1. Store `ui-state` (TASK‑009).
2. Bootstrap слой (TASK‑008).

## Этапы
1. Определить набор компонентов и публичные props.
2. Реализовать состояния:
   - loading;
   - error;
   - access denied;
   - ready.
3. Подключить `BX.UI.Notification` при наличии SDK.
4. Обновить основной view на использование компонентов.

## API‑методы
Не используются напрямую.

## Технические требования
- Стили должны соответствовать Bitrix24 UI Kit.
- Без внедрения сторонних UI‑фреймворков.
- Сообщения об ошибках безопасны к XSS.

## Критерии приемки
- UI структурирован по компонентам.
- Все состояния отображаются корректно.
- Наличие единых уведомлений для ошибок.

## Тестирование
- Режим `allowed=false` (AccessDenied).
- `status=error` (ErrorState + Notification).
- Загрузка (Loader).
