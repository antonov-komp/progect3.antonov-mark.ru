# TASK-файлы

Дата: 2026-01-14 23:19 (UTC+3, Брест)

## Формат
- Каждая задача — отдельный файл `TASK-XXX-*.md`.
- Структура включает: цель, контекст, требования, API-методы, этапы, критерии.

## Процесс ведения задач
1. Основные задачи хранятся в корне `DOCS/TASKS/`.
2. В процессе работы отмечаем прогресс внутри файла задачи.
3. После завершения задача перемещается в `DOCS/TASKS/archive/` со статусом
   `done` и отметкой о результате.
4. Если задачу выполнить не удалось — перемещаем в `DOCS/TASKS/backlog/` со
   статусом `blocked` или `failed` и описанием причины.
