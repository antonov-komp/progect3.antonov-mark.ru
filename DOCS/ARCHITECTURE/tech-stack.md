Обновлено: 2026-01-15 09:39 (UTC+3, Брест)

## Базовые решения
- Bitrix24: облачная версия, интеграция через REST API.
- Backend: PHP (приложение Bitrix24 REST).
- Frontend: Vue 3 (Composition API, сборка Vite), CSS3.
- Деплой: VPS (Linux).

## Версии (актуально для фронтенда)
- Vue: 3.5.26
- Vite: 7.3.1
- @vitejs/plugin-vue: 6.0.3

## Интеграции Bitrix24
- Основной канал: REST API (webhook).
- Документация: https://context7.com/bitrix24/rest/ и https://apidocs.bitrix24.ru/.
- Тип портала: облачный (если будет коробка — описать D7 ORM и `init.php`).

## Логирование и диагностика
- Единый сервис: `app/Services/AppLogger.php`.
- Формат: `YYYY-MM-DD HH:MM (UTC+3, Brest) | key=value`.
- Логирование не прерывает основной сценарий при нефатальных ошибках.
- Fallback: `error_log` при отказе записи.

## Конфигурация окружения
- Секреты хранятся в переменных окружения.
- Webhook URL хранится в настройках приложения или `.env`.
- Сборка Vue формирует ассеты в `public/vue/`.

## Сборка фронтенда (Vue/Vite)
- Установка зависимостей: `npm install` (в каталоге `frontend/`).
- Dev-режим: `npm run dev` (HMR через Vite).
- Production-сборка: `npm run build` (минификация, вывод в `public/vue/`).
- Выходные файлы: `public/vue/app.js` и `public/vue/app.css`.
- Подключение ассетов: `app/index.php` проверяет наличие файлов и вставляет теги.

## Ограничения и принципы
- Интеграции выполняются через REST API Bitrix24.
- Прямые REST-вызовы с фронтенда запрещены, только backend JSON.
- Секреты хранятся только в переменных окружения.
- Логирование ошибок обязательно (AddMessage2Log / Bitrix\Main\Diag\Logger).
