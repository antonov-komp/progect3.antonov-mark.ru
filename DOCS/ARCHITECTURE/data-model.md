# Модель данных

Дата: 2026-01-14 21:42 (UTC+3, Брест)

## Статус
- **Основное приложение**: Собственная БД не используется, данные Bitrix24 через REST API.
- **Модуль outgoing-webhook**: Используется SQLite для хранения событий и очереди обработки.

## Принципы
- Данные Bitrix24 описываются как внешние сущности (через REST API).
- Любые локальные таблицы должны быть документированы в `DB-SCHEMA`.
- Каждое изменение схемы БД фиксируется внизу файла.
- Модуль `outgoing-webhook/` использует SQLite для хранения событий (см. `DOCS/DB-SCHEMA/outgoing-webhook-sqlite.md`).

## Шаблон сущности (локальная БД)
Используйте как структуру описания при появлении таблиц:
1. Назначение таблицы.
2. Поля: тип, ограничения, описание, пример.
3. Связи и индексы.
4. Примеры данных (2-3 строки INSERT).
