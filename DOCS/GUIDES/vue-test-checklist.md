# Vue UI тест‑чеклист

Дата: 2026-01-14 23:47 (UTC+3, Брест)

## Цель
Проверить корректность Vue‑слоя встроенного приложения Bitrix24 после рефакторинга.

## Подготовка
- Сборка фронтенда выполнена: `frontend/` → `public/vue/`.
- Открытие через:
  - embedded‑режим (через Bitrix24);
  - direct‑режим (по прямой ссылке).

## Сценарии (обязательные)
1. **Загрузка**
   - Отображается `LoadingState` при старте.
   - После ответа состояние меняется на контент или ошибку.

2. **Доступ запрещён**
   - `allowed=false` показывает `AccessDenied`.
   - Контент не отображается.

3. **Успешная загрузка**
   - Приветствие (`GreetingMessage`) отображается.
   - Контекст (`AccessContextInfo`) отображается при наличии данных.

4. **Ошибка backend**
   - `status=error` отображает `ErrorState`.
   - Уведомление через `BX.UI.Notification` (если доступно).

5. **Embedded vs Direct**
   - В embedded режиме `auth.source` → `request_token`.
   - В direct режиме выводится предупреждение об открытии в Bitrix24.

6. **Сетевые ошибки**
   - Отключение сети приводит к нейтральной ошибке без падения UI.
   - Повторная загрузка восстанавливает работу.

7. **Контекст запроса**
   - `AUTH_ID`, `DOMAIN`, `member_id` корректно добавляются к запросу.
   - При отсутствии `BX24` запрос выполняется с `APP_REQUEST_CONTEXT`.

8. **Нотификации**
   - `notifyError` отображает сообщение.
   - Уровни уведомлений не ломают интерфейс (info/warning/success).

## Необязательные проверки
- Обработка пустых/невалидных полей в `ui-state` (нормализация).
- Таймаут запросов (abort через 8 сек).

## Критерии успешности
- UI не падает ни в одном сценарии.
- Ошибки отображаются безопасно и нейтрально.
- Структура и стили совместимы с Bitrix24 UI Kit.
