# SQLite База данных для исходящих вебхуков

Дата создания: 2026-01-27 (UTC+3, Брест)

## Описание

SQLite база данных используется для хранения событий исходящих вебхуков вместо файловой системы. Это обеспечивает:

- Быстрый поиск событий по индексам
- Сложные SQL-запросы (JOIN, GROUP BY, агрегации)
- Улучшенную производительность при больших объемах данных
- Упрощенную аналитику и отчетность
- Целостность данных через транзакции

## Требования

### Расширение PHP

Для работы с SQLite необходимо установить расширение `pdo_sqlite`:

```bash
# Для PHP 8.3 (Debian/Ubuntu)
sudo apt-get install php8.3-sqlite3

# Перезапуск веб-сервера
sudo systemctl restart php8.3-fpm  # или apache2
```

**Проверка установки:**
```bash
php -m | grep -i sqlite
# Должно вывести: pdo_sqlite
```

Подробные инструкции по установке см. в `INSTALL.md`.

## Инициализация

### Автоматическая инициализация

База данных автоматически инициализируется при первом использовании через `ServiceContainer`.

### Ручная инициализация

```bash
php tools/init-database.php
```

**Важно:** Перед инициализацией убедитесь, что расширение `pdo_sqlite` установлено (см. раздел "Требования" выше).

## Структура БД

### Таблицы

1. **events** — основные события
2. **task_details** — детали задач
3. **comment_details** — детали комментариев
4. **enriched_data** — обогащенные данные
5. **queue_jobs** — очередь обработки
6. **entity_states** — состояния сущностей
7. **activity_first_metrics** — метрики ActivityFirst

Подробная схема в файле `schema.sqlite.sql`.

## Конфигурация

Настройки в `config.local.php`:

```php
return [
    // SQLite настройки
    'DATABASE_TYPE' => 'sqlite',
    'DATABASE_PATH' => __DIR__ . '/database/events.db',
    'DATABASE_WAL_ENABLED' => 'true',
    
    // Fallback на файлы (опционально)
    'DATABASE_FALLBACK_TO_FILES' => 'false',
];
```

## Использование

### Переключение между БД и файлами

В `config.local.php` установите:

- `DATABASE_TYPE` = `'sqlite'` — использовать БД
- `DATABASE_TYPE` = `'files'` или другое значение — использовать файлы

### Репозитории

Доступны через `ServiceContainer`:

- `eventRepository` — работа с событиями
- `queueRepository` — работа с очередью
- `taskDetailsRepository` — работа с деталями задач
- `commentDetailsRepository` — работа с деталями комментариев
- `entityStateRepository` — работа с состояниями сущностей

## Производительность

- **Целевая нагрузка:** < 50 событий/сек
- **Объем данных:** < 100,000 событий/день
- **Размер БД:** Рост ~1-5 MB/день

## Резервное копирование

Рекомендуется регулярное резервное копирование файла БД:

```bash
# Копирование БД
cp database/events.db database/events.db.backup.$(date +%Y%m%d_%H%M%S)
```

## Миграция данных

Для миграции существующих данных из файлов в БД используйте скрипт:

```bash
php tools/migrate-to-sqlite.php
```

(Скрипт будет создан в рамках задачи TASK-027-06)

## Ограничения SQLite

- Один файл БД (может быть узким местом)
- Ограниченная параллельная запись (WAL режим помогает)
- Нет репликации

Для более высоких нагрузок (> 100 событий/сек) рекомендуется переход на MySQL (TASK-026).
